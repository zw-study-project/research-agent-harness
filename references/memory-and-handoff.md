# Memory and Handoff

Use a bounded `memory/index.md` as always-on routing and topic files as on-demand detail. Write the topic first, then add one short index pointer. Keep the index below 200 lines and 25 KB. Do not save facts derivable from code, registries, or version history. Mark obsolete guidance `superseded` and link its replacement.

Use progress for mutable project state and handoff for immediate recovery. A research handoff records:

- active work item;
- current bounded claim;
- frozen variables;
- last verification command and result;
- changed paths or generated artifacts;
- risks and blockers;
- next evidence needed;
- one exact next command.
