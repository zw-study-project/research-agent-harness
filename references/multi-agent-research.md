# Multi-Agent Research

Parallel work is safe only when every worker has an owner, non-overlapping write scope, explicit inputs, expected output, and one merge authority. Literature themes, independent data audits, frozen-seed runs, and report reviews are common safe splits.

Do not concurrently edit a shared registry, redefine a protocol, update the authoritative current claim, or run formal experiments while another worker changes their resource contract. The coordinator synthesizes evidence and alone updates shared conclusions and state. Workers return artifact paths, commands, results, limitations, and unresolved questions rather than editing the final narrative by default.
