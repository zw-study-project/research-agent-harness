# Research Agent Workflow

## Startup

1. Read the root agent guide.
2. Read project context, research contract, active work item, progress, and handoff.
3. Read `memory/index.md`; load only topics relevant to the active item.
4. Load only the relevant resource, literature, exploration, experiment, and mistake records.
5. Run the fast gate with the declared interpreter and environment.

## Work

Keep one active research item unless owners, write scopes, and merge authority make parallel work independent. Separate code facts, engineering checks, measured evidence, external claims, hypotheses, and interpretations. Never change a scientific variable inside an existing experiment identity.

## End of Session

Run the full gate or record the reproducible blocker. Update work evidence, progress, relevant registries, decisions, and durable memory. Write the current bounded claim, frozen variables, risk, next evidence needed, and one copy-pasteable command in the handoff. Commit only when requested.
