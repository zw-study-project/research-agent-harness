# Research Agent Rules

## Statement Classes

Distinguish code facts, engineering validation, measured research evidence, external claims, hypotheses, and interpretive inference. Never present the latter three as established facts.

## Experiment Discipline

- Smoke verifies execution, not scientific performance.
- Pilot results only determine the registered advancement or no-go decision.
- Freeze a protocol before formal repeated comparison.
- Create a new experiment ID when a scientific variable changes.
- Preserve negative and inconclusive results and immutable run evidence.

## State Authority

`work_items.json` is authoritative for research work. If `feature_list.json` exists, treat it as a compatibility projection rather than an independently editable source.
